# Attribution & Removal Policy

This repository collects and redistributes Lua widgets, preset snippets, and examples for the Electra One MIDI controller. Many of these originate from the [Electra One forum](https://forum.electra.one) and related GitHub repositories.

## Attribution

Every widget imported from an external source MUST include, at the top of `widget.lua` and in the folder's `README.md`:

- Original author (handle or name)
- Source URL (forum thread or repo)
- Import date
- Any license notice present at the source (or "no license specified at source" if none)

## Relicensing

We do **not** relicense third-party code. The `LICENSE` at the root of this repo (MIT) applies to:

- The repository structure, scaffolding, documentation, CI, and gallery
- Widgets authored directly by contributors to this repo

Imported widgets retain whatever license their author applied. Where none was specified, we treat them as "all rights reserved, redistributed with attribution, subject to removal on request" — see below.

## Removal procedure

If you are the author of any content in this repository and want it removed or changed:

1. Open an issue using the [Removal request template](.github/ISSUE_TEMPLATE/removal-request.md), **or**
2. Email the maintainers (see repo owner's GitHub profile)

**Commitment:** we will remove or modify the content **within 48 hours** of a verified request. No justification needed. We may contact you to discuss relicensing but will never delay removal on that basis.

## Good-faith notice

Content is collected in good faith to serve a small, tightly-knit community. If you spot misattribution, missing credit, or anything that feels off — please open an issue. We would rather over-credit than under-credit.
