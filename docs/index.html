Electra One Widgets

A library of custom Lua widgets for the Electra One MIDI controller — a curated design system built from a shared theme + reusable primitives, alongside community ports of widgets shared on the forum.

GitHub · Browser emulator · Contribute a widget

Design System

Original widgets built on lib/theme.lua + lib/primitives/. Shared palette, RGB565-safe, MK2-native 1016×560.

Community ports

Widgets shared by the Electra One community, collected here with attribution. See each README for the original author and source.
